# ⏰ Reminder App

A full-stack Reminder Web Application built using:

- Node.js
- Vercel Serverless Functions
- MongoDB Atlas
- Vanilla HTML/CSS/JS

This app allows users to:

✅ Add reminders  
✅ Store reminders in MongoDB  
✅ Delete reminders  
✅ Get browser alerts at reminder time  
✅ Use Indian Standard Time (IST) timezone  
✅ Deploy completely on Vercel

---

# 🚀 Features

- Full-stack Vercel deployment
- MongoDB database integration
- Responsive UI
- Indian timezone support (`Asia/Kolkata`)
- Real-time reminder alerts
- CRUD Operations
- Serverless API functions
